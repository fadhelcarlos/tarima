# Tarima

Banda virtual en el navegador: batería acústica 3D (y pronto micrófono, ukulele y más) para tocar con los dedos en iPad y teléfono.

- Desarrollo: `npm install` y `npm run dev`
- Publicar en GitHub Pages: `node scripts/deploy.mjs`

## Créditos

- Batería: [Virtuosity Drums](https://github.com/sfzinstruments/virtuosity_drums), de Versilian Studios y Karoryfer Samples (CC0).
- Estudio (HDRI) y texturas de suelo y alfombra: [Poly Haven](https://polyhaven.com) (CC0).
- Las canciones famosas son versiones simplificadas de sus partes de batería, sin el audio original.
